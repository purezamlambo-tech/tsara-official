# Tsara — Portfolio Website

A personal portfolio website for **Tsara**—Dublin-based South African Music Producer, DJ, Sound Designer, and Audio Engineer.

---

## 🌟 Overview

This portfolio showcases Tsara’s creative practice across Amapiano, Afro House, and electronic music production, audio engineering, live DJ performance, and media composition.

---

## 🛠️ Built With

* **HTML5** & **Tailwind CSS**
* **Theme:** Dark Slate (`bg-slate-950`) with Cyan accents (`cyan-400`/`cyan-500`)
* **Hosted on:** GitHub Pages / Vercel
